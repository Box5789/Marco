# 지식그래프 기반 시각 인식 — 보류 연구 메모

2026-09-15. 사용자 요청으로 대화 중 아이디어를 별도 보관한다.
**현재 개발 계획에 추가하거나 구현을 시작한 것은 아니다.**

## 질문과 방향

GNN이나 LLM을 인식기로 쓰지 않고, NAI처럼 명시적인 지식·관계·추론으로
이미지를 해석할 수 있는가? 슈퍼픽셀과 장면 그래프를 활용하는 방향을 검토한다.

제안은 그래프를 인식 결과의 저장소로만 쓰지 않고, **관측한 모양과 관계가
어떤 개념에 해당하는지 판단하는 지식**으로도 사용하는 것이다.
현재 NAI에 이 기능이 구현돼 있다는 뜻은 아니며, 범용 사진 인식이나
기존 시각 모델보다 적은 자원 사용을 보장하지 않는다.

## 구상

1. **저수준 관측:** 슈퍼픽셀·윤곽선·기하 계산으로 색, 경계, 상대 크기,
   위치, 접촉, 이미지 평면에서의 포함 관계 등을 추출한다. 물체 이름을
   이미 알고 있다고 가정하지 않는다. 관측에는 이미지 구간과 불확실성을 남긴다.
2. **개념 지식:** 모양·부분·관계의 조합을 개념 그래프로 표현한다.
   물체별 판단을 엔진의 조건문에 박는 대신 교체 가능한 팩의 지식으로 둔다.
3. **대응과 가설:** 관측 그래프와 개념 지식을 비교한다. 일부 특징이 맞는다고
   곧바로 확정하지 않고 경쟁 후보, 반대 근거, 가려진 부분을 구별한다.
4. **재관측:** 후보를 구별할 근거가 부족하면 관련 이미지 영역을 다시 조사한다.
   지식이 예상한 특징을 실제로 관측한 것처럼 만들어서는 안 된다.
5. **설명·사례 학습:** 사용자 설명이나 긍정·부정 사례에서 재사용 가능한
   시각 개념을 구성하는 방법을 연구한다. 신경망 학습을 전제하지 않는다.
6. **추론 연결:** 추정한 물체·속성·관계를 장면 그래프로 표현해 기존 추론과
   연결한다. 관측·가설·확정 지식의 구분과 출처를 유지한다.

## 작은 첫 실험 후보

사용자가 “삼각형 안에 작은 원이 있는 표식을 루마라고 부른다”고 설명한다.
엔진을 수정하지 않고 새로운 이미지에서 그 개념을 구별할 수 있는지 본다.

- 실제 픽셀에서 모양과 관계를 추출한다. 정답 도형 정보만 받아 푸는 것은
  시각 인식 성과로 세지 않는다. 정답 구조 입력은 추론 부분을 분리하는 대조다.
- 위치·크기·색·배치를 바꾼 사례와, 원이 삼각형 밖에 있는 등의 반례를 포함한다.
- 가림이나 불완전한 경계 때문에 판단하기 어려우면 불확실성을 유지한다.
- 실제 결과, 전체 처리 시간, 최고 메모리, 탐색 후보 수를 함께 확인한다.
- 새 채점기 구축보다 소수 사례의 입력·관측·해석 결과를 직접 확인한다.

이는 관계 중심 시각 개념 실험이지 범용 사진 이해의 증거는 아니다.

## 중요한 한계

- 슈퍼픽셀은 의미 단위가 아니다. 한 물체가 여러 조각으로 나뉘거나,
  물체와 배경의 경계가 충분히 보존되지 않을 수 있다.
- 가장 큰 난점은 조명·시점·가림·배경 변화에도 안정적인 관측 구조를 얻는 것이다.
- 모양의 유사성만으로 사물의 용도·소유권 같은 의미까지 확정할 수 없다.
- 그래프 노드 수가 작아도 대응 관계 탐색이 커지면 느려질 수 있다.
  분할·특징 계산·인덱스 비용까지 포함해 측정해야 한다.
- 예외마다 시각 규칙을 수작업으로 늘리는 방식은 언어 파서의 예문 증설 문제를
  반복한다. 공통 연산과 학습된 개념을 구별해야 한다.
- 게임 엔진에서 객체 정보를 직접 받는 대안은 NPC 관측 연결로는 쓸 수 있지만
  이미지 인식과는 별개다. 캐릭터가 볼 수 없는 정보를 자동으로 주면 안 된다.

## 추가 방향 — 학습 가능한 부품·관계 기억 (2026-09-15)

사용자 요청으로 후속 논의를 저장한다. 아래는 **연구 방향 제안**이며, 구현
시작이나 성능 달성을 뜻하지 않는다.

### 중심 구조

- **관측은 교체 가능한 계산 부품으로:** 슈퍼픽셀 하나에 의존하지 않고 윤곽,
  특징점, 색·질감, 상대 위치·크기를 함께 활용한다. 관측마다 원본 위치와
  불확실성을 남긴다. 픽셀 처리 전체를 지식그래프로 바꿀 필요는 없다.
- **기억과 개념은 그래프로:** 같은 물체의 여러 관찰에서 반복되는 특징,
  조명·배경에 따라 변하는 특징, 특정 시점에서만 보이는 특징을 구분하는
  방법을 연구한다. 신경망을 쓰지 않아도 사례에서 특징을 선택하는 것은 학습이다.
- **개체 기억과 개념 지식을 구분:** 전에 본 물건을 다시 알아보는 것과,
  처음 보는 물건을 같은 범주로 이해하는 것은 다른 능력이다. 전자의 성공을
  후자의 증거로 쓰지 않는다.
- **가설은 재확인을 안내:** 경쟁 후보를 가르는 특징을 찾아 관련 영역을 더
  자세히 분석한다. 후보에 유리한 부분만 고르지 말고 어긋나는 증거도 검토한다.
  예상한 특징과 실제 관측한 특징은 별도다. 영상·다른 노출을 쓸 수 있을 때만
  새로운 관측을 얻을 수 있으며, 같은 사진의 확대·보정은 새 증거를 만들지 않는다.

### 기존 시도의 위치와 다음 실험

`direction.md`의 기존 기록은 COIL 다른 시점 재인식 94.1%, 물건이 화면의
25%인 합성 배경에서 국소화 없음 54.9%를 보고한다. 씨앗 덩이 방식은 같은
차지 조건에서 목표를 주면 90.1%, 주지 않으면 43.8%였다. 이는 과거 실험
기록이며 이번 논의에서 다시 실행하지 않았다. 목표를 안 준 실험도 등록된
100개 물건 중 선택하는 과제이므로 미등록 물체의 거절 능력까지 입증하지 않는다.

현재 그래프 경로의 고정 RGB·질감 구간과 COIL용 어두운 배경 제거는 조명
변화에 대한 점검 대상이다. 조명 실패의 실제 기여도는 아직 따로 재지 않았다.
전체를 다시 만들기보다 아래 두 축으로 이어간다.

1. **자연 사진 재인식:** 몇 장으로 가르친 새 물건을 목표 이름을 주지 않은
   다른 조명·배경 사진에서 찾는다. 조명만 바꾸는 대조부터 시작해 배경을
   추가한다. 물체가 없는 사진과 비슷한 다른 물체에서도 오인식을 확인한다.
2. **작은 관계 개념 학습:** 앞의 도형 실험처럼 새 설명을 듣고 새로운 부품
   조합을 구별하는지 함께 확인한다. 재인식만 잘하는 방향으로 굳지 않도록 한다.

경량성은 거친 후보 탐색 뒤 필요한 부분만 정밀하게 처리하고, 반복 특징을
공유하는 방향으로 추구한다. 그래프 자체가 메모리·시간 절약을 보장하지는
않는다. 기존 러너와 소수 사례의 실제 관측·해석을 우선 활용하고, 새 범용
채점기 구축은 목표로 삼지 않는다. 범용 자연 사진 인식은 여전히 연구 위험이 크다.

## 참고한 원 연구

- [SLIC Superpixels — EPFL](https://www.epfl.ch/labs/ivrl/research/slic-superpixels/):
  슈퍼픽셀 생성. 이것만으로 의미 인식이 이루어지는 것은 아니다.
- [SIGMA: A Framework for Image Understanding — IJCAI 1985](https://www.ijcai.org/Proceedings/85-2/Papers/048.pdf):
  지식 기반 영상 처리, 공간·부분 관계, 상향식 관측과 하향식 가설의 결합 사례.
  현대 NAI와 동일한 구현이거나 범용 시각 인식의 증명은 아니다.
- [Solving Bongard Problems with a Visual Language and Pragmatic Reasoning](https://arxiv.org/abs/1804.04452):
  영상 처리로 추출한 특징을 기호로 바꾸고, 예시에서 시각 개념을 유도한 연구.
  제한된 시각 과제에서의 결과로 해석한다.
- [Distinctive Image Features from Scale-Invariant Keypoints](https://www.cs.ubc.ca/~lowe/papers/ijcv04.pdf):
  조명·크기·회전 변화에 대한 국소 특징과 기하 검증. 범주 개념 학습과는 구분한다.
- [Active Object Recognition Integrating Attention and Viewpoint Control](https://www.cs.toronto.edu/~sven/Papers/cviu97.pdf):
  후보를 구별할 특징에 주의를 두고 시점을 바꾸는 인식 연구.
- [A Retinex-based Image Enhancement Scheme with Noise Aware Shadow-up Function](https://arxiv.org/abs/1811.03280):
  잡음 증폭을 고려한 저조도 보정 연구. 화질 개선을 인식률 향상으로 간주하지 않는다.
