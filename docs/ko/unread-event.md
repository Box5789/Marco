# 못 읽은 사건 뒤에 과거 값을 현재로 확정하지 않는다

## 무엇이 위험했나

    구슬은 18개 있다.        읽음, 상태로 들어감
    구슬 3개를 더 넣었다.     못 읽음 -> 조용히 버려짐
    지금 구슬은 몇 개야?      "18개입니다"  판정 = 계산완료

21이어야 한다. `뺐다`·`주었다` 도 같다 — 15여야 할 자리에 18을 **자신 있게**
내놓는다. 판정이 `계산완료` 라 보류로도 안 잡힌다.

`ReasoningContext.turn` 은 못 읽은 말에 `None` 을 돌려주고 끝났다. 그 말은
기록에 남지 않으므로, 다음 물음은 **그 말이 없었던 세상**의 값을 확정했다.

이 결함은 자리조사 변경이 만든 것이 아니다. 그전부터 있었다.

## 무엇을 했나

기억을 통째로 버리지 않는다. 못 읽은 말을 `unread` 에 남기고, **그 말이 부른
이름**에 대해서만 지금 값을 확정하지 않는다.

    구슬은 18개 있다. / 구슬 3개를 뺐다. / 지금 구슬은 몇 개야?
      -> 이 대화에서 아직 이해하지 못한 말이 있어 지금 값을 확정할 수 없습니다:
         "구슬 3개를 뺐다". 그 말을 풀어 주시면 이어서 계산합니다.

무엇이 막았는지 사람에게 그대로 말한다. 답을 못 내는 것과 **왜 못 내는지**는
다르다.

## 무엇을 막지 않나

- **딴 것을 부른 말.** `단추 이야기는 재밌다` 는 구슬 물음을 안 막는다.
- **물음.** `만약 구슬을 전부 없애면 어떻게 될까?` 는 아무 상태도 안 바꾼다.
  묻는 말은 사건이 아니므로 못 읽었어도 안 막는다. 물음표는 언어팩의
  `문장분리.question_marks` 선언으로 안다.
- **읽을 수 있는 사건.** `구슬 3개를 꺼냈다` 는 그대로 15개를 낸다.

같은 말이 나중에 읽히면 매듭이 풀린다.

## 정정 — 첫 판의 "남은 한계는 다 덜 단정하는 쪽" 은 틀렸다

두 구멍은 **덜 단정하는 쪽이 아니라 틀린 단정을 놓치는 쪽**이었다.

    구슬은 18개 있다 / 3개를 더 넣었다 / 지금 구슬은 몇 개야?
      -> 18개입니다.   대상이 생략돼 이름 비교에 안 걸렸다

    구슬은 18개 있다 / "구슬 3개를 더 넣었다. 지금 구슬은 몇 개야?"
      -> 18개입니다.   메시지가 물음표로 끝난다고 앞의 사건까지 물음으로 쳤다

둘 다 고쳤다.

- **구간마다 가른다.** 물음인지 사건인지는 메시지 전체가 아니라 문장마다 본다.
- **주어가 빠진 수량 사건도 막는다.** 아무 이름도 안 불렀고 수를 담고 있으면,
  수를 묻는 물음에 대해 막는다.

## 정정 둘 — "새 관찰로 풀린다" 의 첫 판은 너무 헐거웠다

첫 판은 해제 함수에 **과거 사실 전체**를 넘겼다. 그러면 예전의 `구슬은 18개 있다`
까지 새 확정 근거처럼 굴어서, 아무 관찰이나 오면 풀려 버렸다.

    구슬 18개 / 3개 더 넣음(못 읽음) / 단추는 5개 있다 / 몇 개야?
      -> 18개입니다.   딴 대상 관찰이 구슬의 불확실성을 지웠다

    구슬 18개 / 3개 더 넣음(못 읽음) / 구슬 1개를 꺼냈다 / 몇 개야?
      -> 17개입니다.   자신 있게 틀렸다. 정답은 20이다

반례마다 조건을 덧붙이지 않는다. **조건은 하나다.**

> 미해석 사건보다 **나중에**, **같은 대상**의 **같은 속성**을 **실제로 못 박은**
> 관찰만 그 불확실성을 해소한다.

증감은 값을 흔드는 것이지 못 박는 것이 아니므로 세지 않는다. 그래서 기록을
**지우지 않는다** — 못 읽은 말은 그대로 남고, 나중에 못 박힌 값이 이길 뿐이다.

## 새 관찰로 풀린다

    구슬은 18개 있다 / 구슬 3개를 더 넣었다 / 구슬은 21개 있다 / 몇 개야?
      -> 21개입니다.

값을 못 박는 새 관찰이 오면 그것을 막던 말은 풀린다. 영원히 보류하지 않는다.

## 아직 못 막는 것 — 적어 둔다

- 이름으로 가르므로, 이름을 부르되 사건이 아닌 말(`구슬 이야기 재밌다`)도 막는다.
- (고침) 한글 수사는 이제 잡는다. 아라비아 숫자만 보다가 `세 개를 더 넣었다` 를
  놓치고 **18개라고 단정했다.** 수사는 언어팩의 `numerals` 선언에서 읽고, 글자가
  아니라 **낱말째로** 본다 — 글자로 보면 `단추 이야기는 재밌다` 의 `다` 가 `다섯` 에
  걸려 잡담까지 수량 사건이 된다.
- 물음표 없는 물음은 사건으로 본다. 쓸데없는 보류가 는다.

**"남은 건 다 안전한 쪽" 이라고 말하지 않는다.** 그 말을 두 번 했고 두 번 다
틀렸다. 남은 것은 *지금까지 확인한 범위에서* 덜 단정하는 쪽일 뿐이다.
`틀린 단정 0/34` 도 그 34문항에서의 관측이지, 알려진 오답 경로가 없다는 뜻이 아니다.
