# 설명을 듣고, 전에는 못 풀던 물음을 푼다

## 무엇이 됐나

    설명 전 · 민수      "베풀다" 가 무슨 뜻인지 아직 모릅니다. 뜻을 알려주시면…
    설명 후 · 민수      6개입니다.
    설명 후 · 지연      5개입니다.
    처음 보는 사람·수    8개입니다.        <- 서우 10개 / 도아 1개. 외운 것이 아니다
    안 했다면          8개입니다.        <- 안 한 일은 상태를 안 바꾼다
    정의를 바꾸면       5개입니다.        <- 같은 낱말, 다른 정의(3개)

마지막 줄이 핵심이다. **`베풀다` 라는 글자를 보고 정해 둔 동작을 했다면 6이 나온다.**

## 어떻게 했나

언어팩은 **뜻풀이와 사건이 어떻게 생겼는지**만 선언한다.

    "{동사}다는 상대에게 {물건} {수}개를 주는 것이다"
        -> {동사} 를 [ [{주는이} {물건}, count_remove, {수}],
                     [{받는이} {물건}, count_add,    {수}] ] 로 푼다

    "{주는이}가 {받는이}에게 {동사}었다"   -> 그 뜻을 이 두 사람에게 적용한다
    "{주는이}는 {받는이}에게 {동사}지 않았다" -> 적용하지 않는다

**어떤 낱말인지는 코드도 예문도 모른다.** `$verb` 는 슬롯이다. 새 연산을
발명하지도 않는다 — 뜻풀이는 이미 있는 `count_remove`·`count_add` 를 엮을 뿐이다.

뜻은 **그 대화 안에서만** 산다. 한 대화에서 정한 뜻을 온 세상 지식으로 올리지 않는다.
같은 낱말을 다시 설명하면 나중 것이 이긴다.

## 모르는 말은 짚어서 묻고, 버리지 않는다

    민수가 지연에게 베풀었다   ->  "베풀" 이 무슨 뜻인지 아직 모릅니다

읽기는 읽었지만 쓸 수 없는 사건이다. 그냥 거절하는 것과 다르다 — **무엇을 모르는지**
말한다. 그리고 못 읽은 사건과 똑같이 기록에 남겨, 다음 물음이 옛 값을 확정하지
못하게 막는다. 이걸 안 했더니 `8개입니다` 라고 단정했다.

# 2차 — 배운 동사의 활용, 그리고 나중에 들은 설명

## 활용을 잇는다

설명은 `훔치다`, 문장은 `훔쳤다`. 뜻은 알아듣는데 그 말을 쓴 문장을 못 읽던
짝 어긋남을 고쳤다.

    훔치다 -> 훔쳤다 / 훔쳤어 / 훔쳤어요       전부 7개입니다
    퍼주다 -> 퍼줬다        건네다 -> 건넸어요

**임의의 말을 어간으로 오려내지 않는다.** 이 대화에서 **이미 설명받은** 어간만
언어팩의 활용으로 펼쳐 놓고 견준다. 그래서 설명 안 받은 `건넸다` 는 여전히
모르는 말이다 — 모르는 말을 멋대로 쪼개 아는 척하지 않는다.

## 틀에 꼬리를 박지 않는다

처음엔 사건 틀을 `{동사}었다` 로 적었다. 그러면 `-었다` 로 끝나는 말만 읽는다.
다음 판은 `{동사}다` 로 넓혔는데, 이번엔 **꼬리가 슬롯이라 아무 문장이나 삼켰다**
— `베풀었습니` 를 동사로 읽었다.

답은 셋째였다. **동사 자리를 한 낱말로 묶고(`word_slots`) 틀에는 꼬리를 안 둔다.**

    민수가 지연에게 훔쳤어요      -> 사건. verb = 훔쳤어요
    민수가 지연에게 사과를 준다    -> 사건 아님 (두 낱말)
    하루가 지우개를 책상으로 옮겼다  -> 사건 아님

말투는 언어팩의 활용이 이미 다 계산하고 있었다. 틀이 한 말투를 강요하고 있었을 뿐이다.

## 나중에 들은 설명으로 이어 푼다

    민수 구슬 8개 / 지연 구슬 3개
    민수가 지연에게 베풀었다      -> "베풀" 이 무슨 뜻인지 아직 모릅니다
    베풀다는 … 2개를 주는 것이다   -> 알려주신 상태를 반영했습니다
    지금 민수 구슬은 몇 개야?     -> 6개입니다

쓸 수 없던 사건을 **관찰로 남겨 두기** 때문에 가능하다. 그리고 뜻을 알게 되면
그 낱말을 막던 자리도 함께 풀린다.

**앞 사건에 뒤에 고친 뜻을 소급하지 않는다.**

    뜻(2개) / 사건 / 뜻(4개) / 물음   ->  6개입니다.  4가 아니다

사건은 제 차례의 뜻으로 푼다. 그때 아무 뜻도 없었을 때만 나중 설명으로 잇는다.

## 경계 — 여기까지다. 정확히 적는다

**새 낱말은 아무것도 필요 없다.** `훔치다`·`퍼주다` 처럼 어디에도 없는 낱말이
뜻풀이로 읽힌다. 그러나 **새 틀은 선언이 필요하다.**

1. ~~활용을 되돌리지 못한다~~ **2차에서 고쳤다.** 다만 이어지는 것은 **한 대화에서
   설명받은 어간**뿐이다. 설명 없이 처음 보는 활용꼴은 여전히 모르는 말이다 —
   그게 맞다.
2. **연산 조합이 다르면 틀이 하나 더 필요하다.** `빼앗다는 상대에게서 …
   가져오는 것이다` 는 역할이 뒤집힌 조합이라 지금 틀로 안 된다. (평가 문항)
3. **수량 밖은 아직이다.** `치우다는 물건을 상자로 옮기는 것이다` 도 틀이 없다.
   자리 바꾸기 자체는 되므로 막힌 곳은 뜻풀이 틀뿐이다. (평가 문항)

## 다음에 물어야 할 것

낱말은 공짜인데 틀은 선언이 든다. **틀 자체를 사례에서 유도할 수 있는가**가
다음 질문이다. 지금은 답을 모른다. 틀을 하나씩 손으로 더하는 길로 계속 가면
그건 예문 증설과 같은 병이 된다.

먼저 할 것은 1번이다. 뜻은 알아듣는데 그 말을 쓴 문장을 못 읽는 상태가
제일 값싸게 고칠 수 있고, 지금 막고 있는 것도 그것이다.

# 3차 — 틀을 사례에서 꺼낸다

2차 끝에 물었던 것(**틀 자체를 사례에서 유도할 수 있는가**)에 답이 나왔다.
**된다 — 몸통이 이미 아는 문장꼴이면.** 자세한 것은
[틀을 손으로 적지 않고 사례에서 꺼낸다](frame-induction.md).

    숨기다는 물건을 서랍으로 옮기는 것이다 / 민수가 구슬을 숨겼다  ->  서랍에 있습니다
    담다는 구슬 3개를 넣는 것이다        / 하루가 담았다        ->  8개입니다

둘 다 **아무도 선언하지 않은 짜임**이다. 뜻풀이의 겉틀(`{동사}다는 {몸통} 것이다`)
하나와 조사 목록만 선언하고, 몸통은 앞자리를 지운 보통 문장 사례로 읽는다.

위 경계 2·3번은 이렇게 갈린다.

2. `빼앗다` — **여전히 안 된다.** 다만 까닭이 바뀌었다. 틀이 없는 게 아니라
   `가져오다`·`주다` 라는 **움직임**이 없다. 주고받기는 사실이 둘이라 사실
   하나짜리 보통 사례로 적을 수 없다. (평가 문항, 안 고침)
3. `치우다` — **된다.** 틀을 더해서가 아니라 유도로 선다. (평가 문항)
