## What G3.7 changed

## What still says 수선

A realized Korean reply that rests on a repair is prefixed by the realizer's
own declaration, not by the pack template:

| File | Key | Value |
| --- | --- | --- |
| `marco/language/realizer/한국어.json` | `repair_tag.word` | `[수선]` |

So a Korean repaired statement is still spoken as `[수선] "…"를 "…"로 읽습니다 …`
(e.g. `tests/test_repair_and_english.py::test_unmatched_korean_is_repaired_reported_and_answered_in_one_turn`
asserts `startswith("[수선]")`), and the measurement files under
`marco/language/measurements/` quote it.

## Request

If the owner's word applies to the spoken tag too, change `repair_tag.word` to
`[수정]` (and the one assertion in `tests/test_repair_and_english.py:51`). W2
decides whether the tag is spoken or traced (W2.3); G3 changes neither.
